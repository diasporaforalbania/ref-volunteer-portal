# Udhëzues: portali si aplikacion në telefon

Materiale për vullnetarët — si ta shtojnë portalin në ekranin e telefonit.

| Skedari | Për çfarë shërben |
| --- | --- |
| `udhezues-instalimi.pdf` | Udhëzuesi i plotë, A4, 6 faqe. Për shtypje ose dërgim si dokument. |
| `iphone-safari.jpg` | Fleta vetëm për iPhone. Për t'u dërguar në WhatsApp/Viber. |
| `android-chrome.jpg` | Fleta vetëm për Android. |
| `udhezues-instalimi.html` | Burimi. Hapet në çdo shfletues; nga aty mund të printohet ose të ndryshohet teksti. |

Pamjet e telefonave janë ilustrime të vizatuara, jo foto ekrani nga pajisje reale —
butonat mund të kenë emra pak të ndryshëm sipas versionit të telefonit.

Për ta rigjeneruar PDF-në pas ndryshimeve: hapni `udhezues-instalimi.html` në shfletues
dhe printojeni si PDF (A4, me ngjyra/sfond të aktivizuar).
